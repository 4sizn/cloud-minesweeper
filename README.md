# 나의 하늘 · Cloud Minesweeper

Flutter로 만든 iOS / Android용 구름 지뢰찾기 앱입니다. 구름 모양의 지뢰찾기를
완성하면 구름 조각을 수집하고, 휴대폰이 향하는 방향에 배치합니다.

## 실행

이 작업 환경의 Flutter SDK: `/Users/hsshin/.local/share/flutter`.
Flutter 3.47.5 / Dart 3.13.4로 검증했습니다.

```sh
export PATH="$HOME/.local/share/flutter/bin:$PATH"
flutter pub get
flutter run
```

출시 화면에서는 샘플 선택을 제공하지 않습니다. 시뮬레이터의 사진 흐름은
통합 테스트가 실제 사진 fixture를 입력해 검증합니다. 빈 하늘 드래그로 방향을 바꿀 수 있습니다. 실제 iPhone / Android에서는
**기기 방향**을 누르면 OS가 계산한 회전 정보를 사용합니다.
Android용 프로젝트와 공통 코드는 포함되어 있지만 현재 개발 Mac에는
Android SDK가 없어 Android 빌드·실기기 검증은 아직 하지 않았습니다.

## 구현된 흐름

- 카메라 촬영 후 자동으로 찾은 구름 모양으로 게임 시작.
- 사진마다 쉬움·보통·어려움·전문가를 각 25% 확률로 배정. 지뢰 비율 8%·12%·17%·22%.
- 사진 수정·재분석·같은 판 재도전은 난이도 유지. 수집한 구름에도 난이도 저장.
- 사진 방향 보정·중앙 정사각형 분석·구름 영역 자동 선택, 필요할 때 터치 수정.
- 불규칙한 영역의 8방향 지뢰찾기, 첫 클릭 안전, 빈 영역 열기, 깃발,
  숫자 칸 주변 깃발이 맞을 때 한 번에 열기, 승리·패배·재도전.
- 승리한 판만 수집. 한 판의 수집 버튼을 여러 번 눌러도 중복 추가하지 않음.
- 구름을 얻은 뒤 휴대폰을 움직여 방향을 고르고 **여기에 놓기**.
- 구름 드래그로 위치 변경, 드래그 중 시점 고정, 마지막 이동 취소.
- 가까이 ↔ 멀리 슬라이더로 각 구름의 거리(기본의 0.5–6배) 조절. 거리 저장·되돌리기, 가까운 구름을 앞에 표시.
- 배치 대기 중에도 거리 조절 가능. 빈 도감의 미리보기에는 편집 컨트롤을 표시하지 않음.
- 터치 모드의 빈 하늘 드래그, 두 손가락 확대·축소, 구름 목록에서 위치 찾기.
- 기기 방향 모드를 제스처·도감 선택 후에도 유지. 화면 밖 구름의 방향 안내.
- 첫 화면의 미리보기 구름과 하늘 배경도 휴대폰 회전에 따라 이동.
- 이름 바꾸기, 수집 날짜·플레이 시간 기록, 앱 재실행 후 모양·배치 복원.
- 원본 사진은 처리 후 임시 파일 삭제를 시도하며, 앱에는 구름 칸 모양만 저장.
- 플레이 방법, 게임 이탈 확인, 카메라 권한 설정 이동, 개인정보 안내·라이선스·문의 이메일 복사.
- 출시용 아이콘과 iOS 개인정보 매니페스트 포함.
- 네트워크 요청 없이 동작. 앱에 포함된 배경 이미지 사용.

운영자명도 출시 전에 확정해야 합니다. [출시 점검](docs/release/README.md) 참고.

## 이번 버전의 범위

촬영 직후 앱에 포함한 **하늘 분할 모델 + 구름 전용 학습 모델**을 실행합니다.
하늘 모델이 건물·나무를 제외하고 구름 모델이 구름 모양을 찾습니다.
가장 큰 연결 영역을 16×16 게임판으로 만들며, 충분하면 바로 시작할 수 있습니다.
분석 중에는 진행 상태를 표시하고, 구름이 작거나 없으면 재촬영·수정을 안내합니다.

SWIMSEG 공개 사진 1,013장을 내려받아 중복을 제거하고 촬영 날짜를 나눠 학습했습니다.
학습에 쓰지 않은 347장의 셀 IoU는 기존 51.2%에서 79.8%로 개선됐습니다.
이는 해당 낮 하늘 데이터의 영역 일치도이며, 모든 휴대폰 사진의 인식 정답률은 아닙니다.
자세한 지표·분할·재현 방법은 [구름 판독 검증](docs/cloud-evaluation.md)에 있습니다.

두 모델(합계 약 4.9 MB)은 앱에 포함되며 사진을 서버로 보내지 않습니다.
구름 학습 데이터는 CC BY-NC 4.0이므로 현재 모델은 비상업 개발용입니다.
상용 출시는 모델/데이터 교체 또는 별도 허가가 필요합니다.
출처·라이선스는 `assets/models/README.md`에 기록했습니다.
실시간 프리뷰 분석은 아직 없으며 iOS 최소 버전은 16.0입니다.

위치는 동/북/위 기준 방위각·고도각과 상대 거리로 저장합니다. 거리가 2배면 화면 크기는 절반입니다.
GPS 장소에 고정하는 AR 앵커가 아닙니다. 센서는 자기 북쪽을 기준으로 하므로
주변 자기장과 기기 보정 상태에 따라 실제 방향 오차가 있을 수 있습니다.
실기기 센서 값 수신과 변화는 확인했습니다. 자기 북쪽의 절대 정확도, 장시간 발열·배터리는 추가 검증이 필요합니다.

## 저장과 실패 처리

앱 지원 폴더의 `my_sky_v1.json`에 저장합니다. 쓰기는 순서대로 처리하고,
임시 파일을 완전히 기록한 뒤 교체합니다. 직전 정상 파일은 `.bak`에 남깁니다.
읽기 오류가 나면 기존 파일을 덮어쓰지 않습니다. 저장 실패는 화면에 표시하고
다시 저장할 수 있습니다. 아직 완료하지 않은 게임은 앱 종료 시 유지하지 않습니다.

## 검증 명령

```sh
flutter analyze
flutter test
flutter build ios --simulator --debug --target=integration_test/regression_test.dart
flutter drive --driver=test_driver/integration_test.dart \
  --target=integration_test/regression_test.dart \
  --use-application-binary=build/ios/iphonesimulator/Runner.app -d <simulator-id>
```

핵심 테스트는 첫 클릭·지뢰 수·불규칙한 인접 칸, 승패, 수집 중복 방지,
원자적 저장 및 실패 후 재시도, 방향 투영의 극점·경계·확대를 검증합니다.
통합 테스트는 실제 UI로 한 판을 풀고 수집·배치·드래그·되돌리기·복원을 확인합니다.
통합 테스트는 시뮬레이터에서 실행해 사용자의 실기기 도감을 보존합니다.
사진 검증은 공개 검증 사진 3장의 Python/iOS ONNX 셀 결과 일치도 확인합니다.
방향 검증은 센서 이벤트→화면 위치, 배경 픽셀 변화와 360도 복귀를 검사합니다.
`flutter drive`는 검증 화면도 `docs/screenshots/`에 내보냅니다.
실행 결과와 검증 범위는 `docs/verification.md`에 기록했습니다.

## 파일

- `lib/game.dart`: 보드·게임 규칙·수집 조각 데이터
- `lib/collection.dart`: 로컬 저장
- `lib/sky_geometry.dart`: 구면 방향과 화면 좌표 변환
- `lib/sky_home.dart`: 방향 센서·도감·배치 조작
- `lib/capture_screen.dart`: 촬영·자동 분석·선택 영역 수정
- `lib/cloud_analysis.dart`: 사진 전처리·온디바이스 추론·구름 칸 생성
- `lib/play_screen.dart`: 게임 화면
- `docs/original-prd.md`: 원본 PRD 보관본
- `docs/product-decisions.md`: 대화에서 확정한 추가 요구사항
