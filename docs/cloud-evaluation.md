## 크롭과 라벨 정리

COCO 주석은 하늘 전체를 통째로 `clouds`로 칠한 경우가 많다. 그대로 쓰면 "하늘이면 구름"을 배운다.
다음 두 가지로 정리했고, 둘 다 검증·평가 데이터에도 동일하게 적용된다.

1. **라벨 정제**: 구름으로 칠해진 영역에서 명백히 파란 화소(R/B < 0.62)만 제외했다.
   회색·흰색·옅은 구름은 주석 그대로 둔다. 색상 규칙 일부를 라벨에 주입하는 방식이므로,
   아래 비교에서 색상 규칙이 유리해질 수 있는 방향임을 밝혀 둔다.
2. **크롭 선택**: 하늘이 70% 이상인 정사각 창 중 **하늘 화소 대비 구름 비율이 50%에 가장 가까운** 창을
   고른다. 구름과 맑은 하늘이 함께 보이는 크롭만 남는다. 흐린 하늘(구름 95% 이상)은 전체의 15%까지만 받는다.

사진 1장당 크롭 1장, 총 490장. COCO 이미지 ID 해시로 학습 310 / 검증 48 / 평가 132로 나눈다.
같은 사진의 크롭이 두 곳에 나타나지 않는다. 모델은 검증 픽셀 IoU가 가장 좋은 epoch 38(40 중),
16×16 셀 임계값 0.425는 검증 48장의 셀 IoU로만 선택했다. 평가 132장은 어떤 선택에도 쓰지 않았다.

## 학습에 쓰지 않은 132장 평가

IoU는 예측 영역과 주석 영역의 교집합/합집합이다. 사진 정답률이나 실제 iPhone 촬영 성공률이 아니다.
비교 대상은 모델 도입 이전에 앱이 쓰던 색상 규칙(R/B 비율·밝기·채도)이며, 두 방식 모두 같은 하늘 모델로 게이팅한다.

| 지표 | 이전 색상 규칙 | 구름 학습 모델 |
|---|---:|---:|
| 픽셀 IoU | 64.0% | 74.0% |
| 16×16 셀 IoU | 63.5% | 74.2% |
| 최종 구름 조각 IoU | 56.6% | 67.2% |
| 셀 정밀도 | 88.8% | 84.3% |
| 셀 재현율 | 69.0% | 86.1% |

검증 48장에서도 같은 방향이다(셀 IoU 69.0% → 76.6%). 최종 구름 조각 지표에는 밝기·하늘 비율 검사,
가장 큰 연결 영역 선택, 전체를 덮는 구름 경계 거부가 포함된다. 최소 30칸 조건은 분할 정확도에 넣지 않는다.

## 범위와 한계

- COCO 사진은 여러 카메라로 찍은 일상 야외 사진이라 고정 전천 카메라보다 휴대폰 사용에 가깝지만,
  주석은 전용 하늘 데이터셋보다 거칠다. 옅은 권운과 연무는 주석에서 빠지는 경우가 많다.
- 평가 132장은 낮 사진이 대부분이다. 야간, 역광, 도심 반사면의 정확도는 증명하지 않는다.
- 이전 모델과는 평가 데이터가 달라 숫자를 직접 비교할 수 없다. 같은 조건의 비교는 이 표의 색상 규칙 대비 값이다.
- 정밀도는 소폭 낮아지고 재현율이 크게 올랐다. 결과 확인, 직접 영역 수정, 재촬영은 그대로 유지한다.
