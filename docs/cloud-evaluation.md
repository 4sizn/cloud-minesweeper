# 구름 판독 개선 검증 — 2026-09-21

구름 색상 규칙을 SWIMSEG 사진으로 학습한 작은 분할 모델로 교체했다. 건물과 나무를 제외하는 기존 하늘 모델은 함께 사용한다. 사진은 기기 밖으로 전송하지 않는다.

## 데이터와 검증 분리

- 원본 1,013장 다운로드, 픽셀 해시 중복 26장 제외: 총 987장.
- 학습 548장 / 검증 92장 / 평가 347장. **촬영 날짜 단위** 분리, 동일 사진·날짜 중복 없음.
- 모델은 검증 IoU가 가장 좋은 epoch 22. 30 epoch 중 선택. 평가 데이터로 모델이나 임계값을 고르지 않음.
- 16×16 셀 임계값 0.525: 검증 92장으로만 선택.
- 다운로드한 class_dict.csv의 흑백 설명이 실제 정답 PNG와 반대였다. 사진·마스크 대조로 흰색=구름을 확인한 후 최종 학습 및 평가함.
- 최초 잘못된 라벨 해석으로 생성한 중간 결과는 폐기했으며 이 보고서는 수정된 라벨로 다시 학습·평가한 결과다.

## 학습에 쓰지 않은 347장 평가

IoU는 예측 영역과 정답 영역의 교집합/합집합이다. 사진 정답률이나 실제 iPhone 촬영 성공률이 아니다.

| 지표 | 이전 색상 규칙 | 구름 학습 모델 |
|---|---:|---:|
| 픽셀 IoU | 52.0% | 79.5% |
| 16×16 셀 IoU | 51.2% | 79.8% |
| 최종 구름 조각 IoU | 35.0% | 60.3% |
| 셀 정밀도 | 97.3% | 93.7% |
| 셀 재현율 | 51.9% | 84.4% |

최종 구름 조각 지표에는 하늘/밝기 검사, 가장 큰 연결 영역 선택, 전체를 덮는 구름 경계 거부가 포함된다. 지뢰찾기 최소 30칸 조건은 분할 정확도에 포함하지 않는다.

## 범위와 남은 한계

- 싱가포르의 한 전천 카메라가 찍은 낮 하늘 패치다. 다른 지역, 휴대폰 렌즈, 야간·건물·역광의 정확도까지 증명하지 않는다.
- 색상 규칙보다 회색·옅은 구름을 더 많이 찾지만, 매우 옅은 구름(평가 예: 0795)을 놓치거나 작은 구름 사이를 합칠 수 있다.
- 정밀도는 일부 낮아지고 재현율이 높아졌다. 결과 확인, 직접 영역 수정, 재촬영을 유지한다.
- 347장은 3개 촬영 날짜에 묶인다. 날짜 분리는 유사 패치 누수를 줄이지만 넓은 환경에서의 독립 검증을 대신하지 않는다.

## 재현 자료

- `metrics.json`: 전체 지표 및 검증 임계값 비교.
- `split.json`: 1,013개 이미지 ID·날짜·해시·사용 구분(중복 포함).
- `per-image.csv`: 각 검증·평가 사진의 셀 IoU.
- `history.json`: 최종 학습 30 epoch의 검증 기록.
- 사진 원본·체크포인트·비교 그림: `.local-data/clouds/` (Git 제외).
- 학습/평가 명령: `tools/cloud_training/README.md`.
- 모바일 비교용 검증 사진: 각 검증 날짜의 첫 이미지 0443, 0478, 0487. Python ONNX의 최종 셀 집합과 iOS 실제 ONNX 런타임 출력을 비교한다.
