# 대화에서 확정한 제품 방향

2026-09-21

1. 구름 도감: 지뢰찾기에 성공한 구름 조각을 수집해 이어 붙인다.
2. 완성한 구름의 원래 칸 모양을 유지한다. 수집 날짜와 성공 기록을 남긴다.
3. 사용자가 구름 조각을 드래그해 위치를 조절할 수 있다.
4. 별자리 앱처럼 휴대폰의 방향·기울기에 따라 하늘을 둘러본다.
5. 새 구름을 선택하고 휴대폰으로 놓을 방향을 찾은 뒤 배치한다.
6. 구름의 위치는 화면 픽셀이 아닌 하늘의 방위각·고도각·상대 거리로 저장한다.
7. 드래그하는 동안에는 시점을 고정해 센서와 손가락 입력의 충돌을 피한다.
8. 이후 Android 지원을 고려해 Dart + Flutter를 기본 기술로 선택한다.
9. 첫 검증 범위는 카메라·방향 센서와 실제로 조작 가능한 구름 배치다.

## 이번 구현에서의 구체화

- 최초 자동 배치 제안은 사용자의 방향 기반 배치 요구에 맞춰
  '배치 대기 조각 → 방향 찾기 → 여기에 놓기'로 바꾼다.
- 방향 센서가 없는 시뮬레이터나 기기는 터치 탐색을 제공한다.
- 배치는 자유롭게 조정한다. 자동 스냅, 충돌 제한, 구름 자체의 회전·크기 편집은 아직 넣지 않는다. 거리 이동에 따른 원근 크기 변화는 지원한다.
- 같은 보드의 승리는 한 번만 수집한다. 같은 샘플 모양이라도 새 지뢰 배치로
  시작한 게임은 별개의 판이다.
- 첫 화면에 성공하지 않은 수집 조각을 미리 채우지 않는다.
- 저장 완료 전 앱이 종료되어도 손상되지 않도록 임시 파일 교체 방식으로 저장한다.

## 후속 검증

- 구름 전용 모델의 다양한 실제 iPhone 야외 사진 검증.
- 자동 분할의 soft mask, 흔들림 안정화, 연결 영역 처리, 실제 구름의 형태 보존.
- iPhone 실기기 카메라·방향 센서 정합성·발열 측정.
- Android SDK 설치 후 빌드 및 센서·카메라 기기별 검증.

## 0.1.1 촬영 자동 분석

촬영 직후 모델로 하늘을 분리하고 색상 분석으로 구름 영역을 자동 선택한다.
충분한 구름을 찾으면 바로 게임을 시작할 수 있고, 필요할 때만 손으로 수정한다.
하늘 모델은 번들에 포함하며 앱의 사진 처리는 모두 오프라인으로 수행한다.
실시간 프리뷰 분할과 학습된 구름 전용 모델은 이 변경에 포함되지 않는다.

## 0.1.2 판독과 방향 표시

공개 사진으로 학습한 구름 전용 모델을 하늘 모델과 함께 사용한다.
별도 평가 결과와 데이터 라이선스는 `cloud-evaluation.md`에 기록했다.
첫 화면 미리보기와 하늘 배경도 센서 방향에 따라 이동하며, 실기기에서 사용자가 확인했다.

## 0.1.3 깊이 배치

사용자의 Z축으로 더 멀리 보내기 요청을 반영한다. 방위각·고도각을 유지하며
구름별 상대 거리를 0.5–6배로 바꾸고, 화면 크기는 거리의 역수로 계산한다.
겹칠 때에는 카메라 깊이에 따라 먼 구름부터 그리며 앞에 보이는 구름을 선택한다.
하단 가까이 ↔ 멀리 슬라이더는 미리보기, 배치 대기, 이미 배치한 구름에서 동작한다.
저장된 조각의 거리 변경은 되돌리기와 재실행 복원을 지원한다. 기존 도감에서
distance 필드가 없으면 1을 사용해 이전 모습과 호환한다. 미리보기 조절은 도감에 저장하지 않는다.
멀리 있는 작은 조각은 제스처 인식 시점이 아니라 손가락이 처음 닿은 조각을 기준으로 드래그한다.


## 1.0.0 출시 화면과 난이도

- 홈·촬영의 샘플 시작 버튼과 샘플 선택 화면 제거. 홈 각도 숫자와 빈 도감의 거리 슬라이더 제거.
- 촬영마다 4개 난이도를 같은 확률로 결정한다. 연속으로 같은 난이도가 나올 수 있다.
- 쉬움 8%, 보통 12%, 어려움 17%, 전문가 22%의 셀을 지뢰로 배치한다(내림, 최소 1개).
- 모양 수정·자동 분석 재시도·게임 재도전은 난이도를 유지한다. 재도전은 같은 판의 지뢰 시드도 유지한다.
- 난이도는 촬영 결과·게임·도감에 표시한다. 기존 도감에서 필드가 없으면 보통으로 복원한다.
- 자동 선택이 성공하면 수정 도구를 접고, 실패하면 수동 수정을 제공한다. 연결된 30칸 이상에서 시작 가능.
- 앱 안내에 플레이 방법·개인정보 처리 안내·라이선스·문의 이메일 복사 추가. 문의: 4sizn@naver.com.
- 진행 중이거나 성공 후 미수집 상태에서 나가면 확인한다. 도움말·이탈 확인 중에는 플레이 시간을 멈춘다.
- 출시 준비 작업이며 스토어 업로드는 별도다. 모델 사용권한, 운영자명, 공개 지원·개인정보 URL은 출시 점검 문서에서 관리한다.

## 1.0.0 구름 모델 데이터 교체

상업 배포를 막던 SWIMSEG(CC BY-NC 4.0) 학습 모델을 COCO-Stuff 기반 모델로 교체한다.
주석은 CC BY 4.0이고, 사진은 COCO 메타데이터에서 상업 이용과 2차 저작이 모두 허용된 것만 쓴다.
정확도가 더 높았던 이전 모델을 유지하는 대신 라이선스가 명확한 데이터를 택했다.
색상 규칙으로 되돌리지 않았다. 교체 후에도 평가 셀 IoU는 색상 규칙 63.5%보다 높은 74.2%다.
